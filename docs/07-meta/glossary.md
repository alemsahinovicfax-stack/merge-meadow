# Rječnik (glossary)

| Pojam | Definicija u Merge Meadow | Ne miješati s |
|-------|---------------------------|---------------|
| **run** | Jedan pokušaj lane gameplaya od starta do sudara ili finisha (~60–90 s) | session |
| **session** | Sve što igrač odigra u jednom otvaranju app-a (obično 4–6 runova + kamp) | run |
| **level** (run level) | Konfiguracija jednog runa (spawn, brzina, prepreke) — broj 1–100 | kamp level |
| **loot** | Orbs skupljeni u runu, prenose se u kamp | merge |
| **merge** | Spajanje 2 istog tiera u 1 viši u kampu | run |
| **kamp** | Meta hub između runova — merge + upgrade | lane |
| **tier** | Razina orba (T1, T2, T3…) | upgrade level |
| **upgrade** | Trajni magnet/množitelj unlockan resursima | tier |
| **rewarded** | Video oglas po izboru igrača za nagradu | interstitial |
| **slice** | M7 vertical slice — mali polish loop za playtest | launch |
| **greybox** | M6 prototip — placeholder art, jedna mehanika | slice |
| **ARPDAU** | Prosječan prihod po aktivnom korisniku dnevno | LTV |
| **hybrid casual** | F2P s oglasima + laganim IAP | hyper-casual |
