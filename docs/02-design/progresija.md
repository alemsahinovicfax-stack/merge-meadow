# Progresija

## Sažetak

Power-based + content-based: igrač i kamp postaju jači kroz merge resurse i unlock levela runova. Skill je sekundaran (swipe timing).

## Vremenski horizonti

| Horizont | Što se unlocka / mijenja |
|----------|--------------------------|
| Po runu | Orb loot, množitelj primijenjen, eventualno revive |
| Po sesiji (8–15 min) | 1–2 merge tiera, progress prema sljedećem upgradeu |
| Dnevno | Daily chest, daily challenge run, streak bonus |
| Tjedno / meta | Novi ljubimac, kamp vizual tier, teži level pool |

## Tip progresije

- [ ] Skill-based (igrač postaje bolji) — minimalno (bolji swipe timing)
- [x] Power-based (magnet, množitelj, merge tier)
- [x] Content-based (leveli 1–100, endless, generator mjesec 2)
- [x] Kombinacija power + content

## Curve težine

| Faza | Run leveli | Težina | Cilj |
|------|------------|--------|------|
| D1 | 1–10 | Niska — rijetke prepreke | Player promise, prvi merge |
| Tjedan 1 | 11–40 | Srednja — više orbova, brži scroll | 4–6 runova/dan |
| Mid (launch) | 41–100 | Rampa — rijeđi orbs, više prepreka | Retention + ads |
| Post-launch | Endless + generator | Procedural | D30 bez content droughta |

**Pravilo:** fail mora i dalje davati 50% loota — težina ne smije “prazniti” run (Pillar 1).

## Offline progresija

- Kamp i merge rade **offline**.
- Daily reward se synca na login.
- Nema PvP / server authority u v1.

## Prestige / reset

**OUT za v1** — nema prestige mehanike na launchu.

## Monetizacija i progresija

| Točka | Ponašanje |
|-------|-----------|
| Grind previše spor | Rewarded bonus loot ili IAP starter pack — ne paywall |
| Whales | Nema posebnog whale contenta u v1 |
