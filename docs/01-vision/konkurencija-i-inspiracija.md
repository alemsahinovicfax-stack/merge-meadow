# Konkurencija i inspiracija

## Sažetak

Tri referentne igre — uzimamo **komercijalno dokazane** obrasce (session, meta, monetizacija), izbjegavamo **scope koji solo student ne može povući**.

## Referentne igre

### 1. Mob Control

| Aspekt | Bilješka |
|--------|----------|
| Platforma | Android, iOS |
| Žanr | Hybrid casual — arcade + meta |
| Što uzimamo | Kratki arcade core + meta sloj, hybrid ads/IAP, jednostavan vizualni hook, masovni appeal |
| Što izbjegavamo | Horde/crowd mehanika velikog scopea, preagresivni ad pacing usred akcije |
| Link | [Google Play — Mob Control](https://play.google.com/store/apps/details?id=com.vincentb.MobControl) |

**Komercijalni takeaway:** Dokaz da jednostavan core + meta može nositi hybrid prihod bez mid-core budžeta.

### 2. Merge Mansion

| Aspekt | Bilješka |
|--------|----------|
| Platforma | Android, iOS |
| Žanr | Merge puzzle + meta kamp |
| Što uzimamo | Kamp kao D7 retention, merge 2→1 satisfying loop, IAP na speed-up i conveniences |
| Što izbjegavamo | Narrativ, cutscenes, ogroman content pipeline, energy koji blokira core |
| Link | [Google Play — Merge Mansion](https://play.google.com/store/apps/details?id=com.everydaygames.merge) |

**Komercijalni takeaway:** Merge meta je IAP engine — uzimamo ekonomiju i “kamp te zove natrag”, ne priču.

### 3. Subway Surfers

| Aspekt | Bilješka |
|--------|----------|
| Platforma | Android, iOS |
| Žanr | Endless runner / arcade |
| Što uzimamo | ~90 s session, one-thumb kontrole, rewarded revive, daily/high-score povratak |
| Što izbjegavamo | Čisti endless bez merge meta, samo cosmetics bez kamp progresije |
| Link | [Google Play — Subway Surfers](https://play.google.com/store/apps/details?id=com.kiloo.subwaysurf) |

**Komercijalni takeaway:** Zlatni standard session lengtha i ad placementa **na kraju runa**, ne usred gameplaya.

## Diferencijacija

**Zašto igrač bira Merge Meadow umjesto gore navedenih?**

Merge Meadow spaja kratki lane run (kao Subway Surfers) s cozy merge kampom (kao Merge Mansion) u jednom pastelnom paketu — bez priče i bez paywalla na coreu, s fair F2P monetizacijom kao kod najboljih hybrid casuala (Mob Control).

## Tržišni gap

| Problem kod konkurencije | Naša prilika |
|--------------------------|--------------|
| Pure runneri — slab D7 bez meta | Run hrani merge kamp → povratak sutra |
| Pure merge — manje sesija/dan, manje ad slotova | 4–6 runova/dan + kamp = više ARPDAU |
| Merge Mansion — težak scope (priča, content) | Isti merge feel, solo-friendly scope |
| Generic hyper-casual — nizak LTV | Hybrid casual LTV (ads + IAP) |

## Trendovi (2025–2026) koje pratimo

- **Hybrid monetization** — rewarded + IAP, ne samo jedno
- **Hybrid casual** — jednostavan hook + lagana meta (ne mid-core)
- **Fair F2P** — loši paywalli = loši reviewi = manje downloada
- **Cute / satisfying vizuali** — organski share na TikTok/Reels

## North star za feel

**Subway Surfers** = session tempo i kontrole · **Merge Mansion** = kamp zadovoljstvo · **Mob Control** = hybrid commercial structure
