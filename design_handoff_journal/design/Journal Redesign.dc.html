BloomRow — four states, one layout
1:1 at 1080 base. The row never changes size; only fill, slots and caption do. A filled slot is a dark well in a rim (cream = sprout / bloom, gold square = crystal). A missing tier is an empty ring. NEW adds the pill, rewrites the caption and puts a pink halo on the tier that arrived.
