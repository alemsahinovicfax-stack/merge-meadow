# Privacy policy (public web)

Static page for Google Play / App Store.

## URL (after GitHub Pages is enabled)

`https://alemsahinovicfax-stack.github.io/merge-meadow/`

## Enable Pages (one-time)

1. **Repo visibility:** Settings → General → **Change visibility → Public**  
   (Free GitHub: Pages on private repos needs a paid plan.)
2. **Pages source:** Settings → **Pages** → Build and deployment → Source: **GitHub Actions**
3. Push to `master` (or run workflow **Privacy policy Pages** manually)
4. Open the URL above in incognito; paste into Play Console → Privacy policy
